# Projeto Nubak

Redesign conceitual independente do Nubank, criado por Chrystian para portfólio. Sem vínculo ou aprovação da marca.

## Experiência

- Composição tridimensional de cartões em CSS, com movimento de ponteiro.
- Produtos em abas acessíveis, com suporte a teclado.
- Demonstração interativa do app, com dados fictícios.
- Layout responsivo, navegação mobile, FAQ e diálogo acessível.
- Animações com IntersectionObserver e suporte a prefers-reduced-motion.
- HTML, CSS e JavaScript nativos, sem dependências de execução.

## Executar

Sirva `dist/` com qualquer servidor estático, por exemplo `python3 -m http.server 3000 --directory dist`.

## Vercel

Framework: Other. Sem instalação ou build. Output directory: `dist`.

Design e desenvolvimento: Chrystian. Imagem de referência e marcas: Nubank. Fonte: DM Sans, Google Fonts. Cartões e interface são ilustrações criadas em CSS, não produtos reais.
